# 论文精读 04 · DiT（Diffusion Transformer）

> **Scalable Diffusion Models with Transformers**
> William Peebles (UC Berkeley / NYU), Saining Xie (NYU)
> ICCV 2023 (Best Paper 候选) · arXiv:2212.09748
> 官方代码：https://github.com/facebookresearch/DiT

---

## 1. 一句话概括

把扩散模型的主干网络从 U-Net 换成 **ViT 风格的 Transformer**，
并证明**架构本身不是瓶颈、可扩展性才是**：用同一套超参，只要增大 patch 更细 / 模型更宽更深，
Gflops 与 FID 之间呈现稳定的负相关；在 ImageNet 256×256 类条件生成上做到 FID 2.27，超过所有先前的扩散模型。

## 2. 动机

- 扩散模型在过去两年几乎清一色用 U-Net（源自像素级任务的需求），而 **Transformer 在视觉识别、NLP、多模态里已经全面证明了可扩展性**。
- 一个自然的问题：U-Net 的卷积归纳偏置对扩散模型是必需的吗？还是只是历史惯性？

## 3. 方法

### 3.1 Patchify

把 VAE 隐变量 $z$（$H/p \times W/p$ 个 patch）线性投影成 token 序列，
$p\in\{2,4,8\}$ 直接决定 token 数与算力（**$p$ 减半 → Gflops 约 4 倍**）。

### 3.2 DiT block：三种条件注入方案

| 方案 | 做法 | 成本 | 效果 |
|------|------|------|------|
| in-context | 把 $t$、$y$ 当额外 token 拼进序列 | 几乎零 | 最差 |
| cross-attention | 额外一层 cross-attn | +15% Gflops | 中等 |
| **adaLN-Zero** | 用 $t+y$ 回归出 scale/shift/gate，作用于 LayerNorm 后；**并额外回归一个与残差分支相乘的 gate，初始化为 0** | 最低 | **最好** |

**adaLN-Zero 的"零初始化"是关键**：每个 block 初始时恒等（gate=0 → 残差分支不生效），
这让很深的网络在训练初期等价于浅网络，训练稳定性显著提升。
这是一个很聪明、成本极低、并且可被广泛迁移的技巧（后续 PixArt、SD3、FLUX 都在用）。

### 3.3 模型规模

DiT-S/B/L/XL 四档（32M ~ 675M），patch size 2/4/8 三档，共 12 个模型做可扩展性扫描。

## 4. 主要实验结论

| 结论 | 数据 |
|------|------|
| 可扩展性 | 在固定采样算力下，**Gflops 越大 FID 越低**，相关性极强（Pearson 系数很高） |
| SOTA | DiT-XL/2 + classifier-free guidance：ImageNet 256×256 **FID 2.27**（当时扩散模型最佳），512×512 FID 3.04 |
| 采样算力不是决定因素 | **增大模型比增加采样步数更划算**：一个 118.6 Gflops 的大模型用 128 步，优于 80.7 Gflops 的小模型用 400 步 |
| 训练效率 | 大模型收敛更快（更少的训练迭代达到同等 FID） |

## 5. 我的理解与思考

1. **"用 Gflops 而不是参数量作为横轴" 是这篇论文方法论上最漂亮的一笔**。
   因为 patch size 和深度/宽度都会影响算力，只有把算力统一到一个可比的量纲上，
   "可扩展性" 这个命题才可证。我以后做架构对比实验时也应该这样控制变量。

2. **adaLN-Zero 的零初始化 gate 值得单独记住**。它不是新发明（源自 Gated 残差 / NFNet 的思路），
   但它精准解决了"条件注入 + 深度网络初始化"的耦合问题。
   我在写自己的扩散代码时也可以直接用：把"条件"变成对残差分支的门控，而不是直接加偏置。

3. **U-Net 的归纳偏置在数据量足够时被换掉，但这不代表 U-Net 没用**：
   在数据稀缺、分辨率极高、或需要精细空间对齐（如 inpainting / 超分）的场景，
   U-Net 的局部性仍然是优势。DiT 的成功前提是「有 latent 压缩 + 有大数据」。
   这提示我：**架构选择是和数据规模、计算预算绑定的，不存在绝对最优。**

4. **"增大模型比增加采样步数更划算" 这个结论对工程实践有直接指导意义**：
   与其在推理时堆采样步数，不如把预算投到训练更大的模型上。
   这也从侧面解释了为什么后来社区一边做模型增大（SD3 8B、FLUX 12B），一边做步数蒸馏（4 步采样）。

5. **局限**：全局 self-attention 的 $O(N^2)$ 代价在高分辨率下很重；
   DiT 原文最高只做到 512×512，更高分辨率仍需 cascade 或分块/稀疏注意力。
   → 这是我 idea-01 的直接出发点。
