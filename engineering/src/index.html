扩散模型交互式可视化实验台

把扩散模型的「加噪 / 去噪」过程摊开来看

Diffusion Lab 是一个零依赖、可离线运行的单页应用。它不调用任何后端模型， 所有计算（闭式前向加噪、噪声调度曲线、解析 score 反向采样）都在浏览器里实时完成， 用来把 DDPM / DDIM 论文里的公式变成能拖、能看、能对比的东西。

① 前向加噪

用闭式公式 q(x_t|x_0) 把一张图从 x₀ 一路推到纯噪声，可播放、可拖时间步、可换噪声场，也支持上传自己的图。

② 噪声调度对比

linear / cosine / quadratic / sigmoid 四种 β 调度的 β_t、ᾱ_t、log-SNR 曲线对比，以及同一时间步下的实际加噪效果差异。

③ 反向采样（2D）

在高斯混合玩具数据上用解析 score 真实跑一遍 DDPM 与 DDIM 反向过程，对比不同采样步数下的质量与耗时。

④ 公式速查

DDPM / DDIM 的关键公式与参数化对照，包含 ε 预测与 score 之间的关系。

关键公式速查

前向（闭式）

q(xt|x0) = N( √ᾱt x0, (1−ᾱt) I )

αt=1−βt，ᾱt=∏s≤t αs。整条马尔可夫链可以一步跳到任意 t。

训练目标

Lsimple = Et,x₀,ε ‖ ε − εθ( √ᾱt x₀ + √(1−ᾱt) ε, t ) ‖²

丢掉了 ELBO 中的权重系数，让容量在所有噪声级别上均匀分配。

ε 与 score 的关系

ε* (xt, t) = − √(1−ᾱt) · ∇x log pt(xt)

预测噪声 ≡ 预测 score，二者只差一个随 t 变化的标量系数。

由 ε 反推 x₀

x̂₀ = ( xt − √(1−ᾱt) · εθ ) / √ᾱt

DDPM 反向（随机）

xt−1 = 1/√αt ( xt − βt/√(1−ᾱt) · εθ ) + σt z

σt² = βt（或后验方差 β̃t）。每步都要注入随机噪声。

DDIM 反向（确定性）

xt−1 = √ᾱt−1 · x̂₀ + √(1−ᾱt−1−σt²) · εθ + σt z

σt=0 时完全确定性，对应一个 ODE，因此可以在子序列 τ 上大步跳过。

两种采样器的分工

  • DDIM：把样本"送到"某个模式（低频/语义），步数可以极少。
  • DDPM 的随机项：负责模式内的高频细节与多样性，步数少了会崩。

cosine 调度

ᾱt = cos²( ((t/T + s)/(1+s)) · π/2 ) / cos²(s·π/2)

s=8e-3。让 ᾱ 在前段下降更缓，减少"纯噪声区"的浪费步数。

公式引自 Ho et al. (NeurIPS 2020) 与 Song et al. (ICLR 2021)，排版为本页面的简化写法。
